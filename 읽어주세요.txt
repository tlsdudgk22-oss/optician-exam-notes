안경사 국시 강의노트 — 오프라인 · PWA · Gemini AI 튜터판

[1. 여는 법]
- 간편 실행: index.html 을 더블클릭하면 브라우저에서 바로 열립니다.
- 데스크톱 앱(PWA) 설치 실행: 앱_실행.bat 을 더블클릭하면 로컬 서버(http://127.0.0.1:8765)로 열리며, 크롬·엣지 왼쪽 메뉴 하단의 '앱으로 설치' 버튼 또는 주소창 설치 아이콘으로 데스크톱 앱처럼 설치할 수 있습니다.
- img / fig / fonts / icons / manifest.webmanifest / sw.js 파일을 index.html 과 같은 폴더에 그대로 두어야 그림과 앱 설치 기능이 정상 동작합니다.

[2. 모바일 앱(PWA)으로 설치하는 법]
- 이 폴더 전체를 GitHub Pages, Cloudflare Pages, Netlify 같은 무료 HTTPS 정적 호스팅에 올린 뒤 휴대폰 브라우저에서 접속하세요.
  · 안드로이드(크롬): 왼쪽 메뉴 '앱으로 설치' 또는 브라우저 메뉴 → '앱 설치'
  · 아이폰(Safari): 하단 공유 버튼 → '홈 화면에 추가'
- 한 번 열어 캐시된 뒤에는 인터넷 없이도 문제 풀이·강의·계산 드릴을 앱처럼 사용할 수 있습니다.

[3. AI 튜터 활성화 (Gemini API)]
- 문제 풀이(채점 전 힌트 모드 / 채점 후 해설 모드), 풀이 비법 카드, 개념 강의(본문 드래그 시 '고른 부분 튜터에게 묻기')에서 AI 튜터를 바로 사용할 수 있습니다.
- 최초 1회 Google AI Studio(https://aistudio.google.com/apikey)에서 발급받은 Gemini API 키를 튜터 상단의 'API 키 입력' 칸에 저장하면 활성화됩니다.
- 모델 선택: 빠르게(Gemini 3.5 Flash-Lite) / 보통(Gemini 4 Hydrogen) / 정밀하게(Gemini 4 Argon)
- 보안 안내: API 키는 이 브라우저의 localStorage 에만 저장되며, 진도 동기화 파일(.json)이나 진도 코드에는 절대 포함되지 않습니다. (AI 튜터 호출 시에는 인터넷 연결이 필요합니다.)

[4. 진도 저장 및 클라우드 자동 동기화]
- 풀이 기록·오답노트·북마크·강의 완료·비법 외움·계산 드릴 설정 및 최고 기록은 브라우저에 자동 저장됩니다.
- 왼쪽 메뉴 '진도 동기화 → ① 클라우드 자동 동기화'에서 나만의 암호(4자 이상)만 입력하면 PC·갤럭시·아이폰 어디서든 파일 선택 없이 실시간 자동 저장·병합됩니다. (종단간 AES-256 암호화 적용)
- 보조 수단으로 ② 로컬 폴더 동기화 파일, ③ 진도 파일(.json) 백업, ④ 진도 코드 복사/붙여넣기도 함께 지원합니다.
